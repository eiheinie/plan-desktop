# 计划

一个在本机运行的 Windows 桌面计划表。左侧整理任务，右侧用从上到下的日期轴展示任务的开始日与截止日。

## 功能

- 自定义任务内容、开始时间和截止时间，精确到分钟。
- 每日任务单独管理，设置一次每天重复；可选每日截止时间，按日期保留完成记录。
- 纵向日期跨度图，支持跨月任务、月份切换、今天定位与紧凑视图。
- 鼠标上下拖动卡片排序，双击编辑；支持完成、恢复和删除。
- 右上角切换当前 Windows 用户的开机自启动。
- 任务自动保存在本机文件中，保留上一版备份，也可手动导出 JSON。
- 支持高 DPI 屏幕；无第三方前端依赖，无需注册账号。

## 下载与安装

环境要求：Windows 10 / 11、Microsoft Edge 或 Google Chrome，以及 **Node.js 22 或更高版本**。

1. 从 [Releases](../../releases/latest) 下载 `plan-desktop-v1.0.0.zip` 并解压。
2. 如果尚未安装 Node.js，从 [Node.js 官网](https://nodejs.org/) 安装符合要求的版本。
3. 在解压目录打开终端，运行：

   ```powershell
   node install.mjs --dir "E:\计划" --autostart
   ```

4. 双击桌面上的 **计划**。软件会以浏览器独立窗口打开。

`--dir` 可替换为其他可写文件夹；省略时安装到当前用户的本地应用目录。`--autostart` 用于开启自启动，不指定时保留已有设置。日后可直接在界面中切换。

安装程序会复制当前使用的 Node.js 可执行文件到安装目录，创建桌面快捷方式，并保留安装目录中已有的 `data` 文件夹。发布包不包含 Node.js 二进制文件。

## 使用

点击「新建任务」填写任务和日期。右侧彩色长条覆盖任务开始日到截止日，开始与截止时间显示到分钟；色块高度按自然日计算，不表示小时比例。

左侧卡片可以上下拖动排序，也可在卡片获得焦点后按 `Alt + ↑ / ↓`。双击卡片或时间条打开编辑框。跨月任务在对应月份继续显示，边缘箭头表示任务延伸到相邻月份。

切换左侧「每日任务」，点击「添加每日任务」，填写任务和可选的每日截止时间。勾选只影响当天，下一天自动变为待完成；无需每天重新创建。打开的窗口会在跨日后自动更新，也会在回到窗口时检查日期。每日任务同时显示在右侧时间表最左侧：每项任务一列，每天一个格子，绿色勾选表示该日已完成，双击格子编辑每日任务。

日期图上方的「图块宽度」滑块可随时调整任务宽度，浏览器会记住上次设置。

## 数据与备份

任务存放在安装目录的 `data/tasks.json`，上一版为 `data/tasks.json.bak`。第一次保存旧版任务时会额外保留 `.legacy` 文件。读取主文件失败时，程序会尝试备份恢复，并保留损坏文件。

仓库和下载包不包含个人任务、运行日志、浏览器缓存、凭据或本机运行环境。清除浏览器缓存不会删除任务；移动电脑前请自行备份整个 `data` 文件夹。界面的「导出备份」也可导出 JSON。

本地服务只监听 `127.0.0.1:17643`，不上传任务。关闭窗口后，服务继续在后台运行，下一次打开会复用服务。电脑重启后，桌面快捷方式或自启动入口会重新启动服务。

## 源码运行与测试

```powershell
git clone https://github.com/eiheinie/plan-desktop.git
cd plan-desktop
npm start
```

没有 npm 第三方依赖，无需 `npm install`。

```powershell
npm test
npm run check
```

测试使用临时任务目录和模拟的自启动设置，覆盖旧版日期迁移、同日及跨月跨度、闰年、排序、文件保存与重启、版本冲突、备份恢复及本地 API 的请求校验，不会修改日常任务和真实自启动设置。

## 文件结构

| 文件 | 用途 |
| --- | --- |
| `index.html` / `style.css` | 界面和样式 |
| `app.mjs` | 任务交互与日期跨度图 |
| `model.mjs` | 日期、排序、迁移和输入校验 |
| `server.mjs` | 本地服务、数据保存和自启动 |
| `install.mjs` | Windows 安装与桌面快捷方式 |
| `test/plan.test.mjs` | 自动化测试 |

## 更新与卸载

更新前先备份 `data`。下载新版源码或发布包后保留该目录，再替换程序文件；运行中的后台服务需要退出后重新启动才能加载服务端更新。

卸载前在界面关闭自启动，并备份需要的任务。退出计划窗口，在任务管理器中结束命令行指向该安装目录 `server.mjs --serve` 的 Node.js 进程，再删除安装目录和桌面快捷方式。请勿结束其他软件的 Node.js 进程。

## 已知限制

- 当前主要面向 Windows，依赖 Edge 或 Chrome 显示窗口。
- 同时打开多个窗口时，旧版本保存会被拒绝并刷新数据，避免覆盖另一个窗口的修改。
- 固定使用端口 `17643`。若被其他程序占用，启动会停止，并在安装目录的 `service.log` 中记录原因。
- 切换自启动仅影响当前登录的 Windows 用户，不需要管理员账户。

普通任务和每日任务均可填写详情（最多 5000 字），时间表在标题下以小字显示。空间不足时截断显示，鼠标悬停可查看全文，双击可编辑。
